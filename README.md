# จดกัน (Jotgun)

PWA จดรายรับรายจ่ายส่วนตัว อ่านสลิปโอนเงินธนาคารไทยให้อัตโนมัติ มีแมวข้าวตังเป็นเพื่อนจด
ใช้บน iPhone ผ่าน Safari แบบ "เพิ่มไปยังหน้าจอโฮม" และเปิดบน iPad หรือคอมได้ด้วย
ข้อมูลทั้งหมดอยู่ในเครื่อง (IndexedDB) ไม่มี backend

ใช้งานได้ที่ https://jotgun.vercel.app

## ทำอะไรได้

- **อ่านสลิป:** เลือกรูปสลิป แอปอ่าน QR และ OCR ให้ แล้วพักไว้ในหน้า "รอจด" ให้เลือกหมวดก่อนบันทึก
- **จดเอง:** ใส่รายรับรายจ่ายเอง เลือกหมวด ตั้งหมวดเองได้
- **งบและแผน:** ตั้งงบรายเดือนรายหมวด มีกราฟเทียบกับแผน วงงบแตะค้างเพื่อปรับได้
- **สรุปและค้นหา:** สรุปรายสัปดาห์/เดือน/ปี ค้นหาตามร้านหรือหมวด สำรองและกู้ข้อมูล
- **ธีม:** ธีมธรรมดา (สว่าง มืด กรมท่า พลัม หรือตามระบบ) และธีมข้าวตังที่มีฉากขยับได้ (ทะเลยามค่ำ หน้าฝน นอนดูดาว) โลโก้เปลี่ยนสีตามธีม
- **จอกว้าง (ตั้งแต่ 1024px):** แถบเมนูด้านซ้าย แถบบนพร้อมช่องค้นหา หน้าภาพรวมแบบแถว และตารางรายการที่เปลี่ยนหมวดทีละหลายรายการได้ ปุ่มลัด `/` ค้นหา, `N` จดรายการ

## เทคโนโลยี

- Vite + React + TypeScript, vite-plugin-pwa (Workbox)
- Dexie (IndexedDB)
- OCR: tesseract.js (tha+eng) ใน Web Worker, QR: jsQR
- กราฟ: Recharts, ไอคอน: Font Awesome, อนิเมชัน: framer-motion
- ข้าวตังแบบ 3D: three.js (ปั้นใน Blender)

## พัฒนา

```bash
npm install
npm run dev        # เปิดบนมือถือใน Wi-Fi เดียวกันที่ http://<IP เครื่อง>:5173
npm test           # Vitest: ตัวอ่านสลิป, หมวดอัตโนมัติ, ฐานข้อมูล, คอนทราสต์ของธีม ฯลฯ
npm run build
```

ผ่าน http บน LAN iOS จะไม่ลง service worker (ออฟไลน์และ "เพิ่มไปยังหน้าจอโฮม" แบบเต็มต้องใช้ HTTPS เช่นบน Vercel)

## Deploy

เชื่อม repo นี้กับ Vercel แล้วทุก push เข้า `main` จะ deploy ให้อัตโนมัติ (ค่าตั้งใน `vercel.json`)

## โครงสร้าง

- `src/slip/` อ่านสลิป: ย่อรูป → QR → OCR → แยกข้อมูล (`parse.ts`, โปรไฟล์ธนาคารใน `banks.ts`)
  เจอสลิปที่อ่านผิด ให้เพิ่มข้อความ OCR (ปิดชื่อ/เลขบัญชี) ลง `src/slip/__tests__/fixtures.ts` แล้วแก้ให้ test ผ่าน
- `src/db/` ฐานข้อมูลและ logic ของสลิป หมวด งบ สำรองข้อมูล (จำนวนเงินเก็บเป็นสตางค์)
- `src/features/` หน้าจอของมือถือ
- `src/wide/` เลย์เอาต์จอกว้าง (โหลดเฉพาะบนจอกว้าง)
- `src/design/` สีของทุกธีม (`tokens.css`), รายชื่อธีม (`themes.ts`), component, ฉากธีมข้าวตัง (`decor/`)
- `src/mascot/` ข้าวตัง: ภาพนิ่ง WebP และโมเดล 3D
- `src/assets/logo/` โลโก้และไอคอนแอป แยกไฟล์ตามธีม
- `tools/blender/khaotang.py` ต้นฉบับโมเดลข้าวตัง
